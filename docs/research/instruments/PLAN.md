# Dossier plan — every instrument we write up, in date order, with status

> **The working list for Stage 4.** One line per instrument (or per bundle that one dossier
> covers). Pick the next item from here, write it, tick it here in the same commit. New
> instruments found while writing a dossier are added here at once, in date order, with the
> dossier that found them. The register (`../ordinances_register.md`) stays the full inventory
> with gists and keys; this file is the queue. Rubric and template: `README.md`.
>
> Status: ☑ dossier written · ☐ to write · ◐ covered as a section of another dossier (no own
> file planned) · ✖ no dossier (policing / tariff clause — register row is enough). Tier: **A**
> sets a standard (pieces per mark, lod/karat, tariff that redefines a coin, mint contract
> with parameters) → own dossier; **B** tariff / ban / minting order → folded into the nearest
> A dossier as a section unless it carries parameters of its own; **C** administrative → ✖.
> Order of work: A items in date order, then the B items not yet folded; a reader's request
> or a per-Fuß review may pull one forward.
